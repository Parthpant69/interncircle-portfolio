# Parth Pant | Personal Portfolio

InternCircle Fullstack Web Development, Project 01. This static portfolio uses HTML5 and CSS with no build step or external asset dependencies.

## Preview

Open `index.html` in a browser. The stylesheet and `images/` folder must stay next to it.

## Before publishing

Review the draft introduction, skills, and project descriptions. In the Contact section of `index.html`, replace the placeholder paragraph with a list of your confirmed email, GitHub profile, and LinkedIn profile links. Use `mailto:` for the email link and `class="text-link"` for each link.

Create a public GitHub repository and upload the contents of this folder, keeping `index.html` at the repository root. In **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, and save. Open the published site and test the contact links on your phone.

## Design decision

I used CSS Grid for the project cards so they appear side by side on larger screens and stack into one column on phones. Each card keeps its image, title, and description together as the screen narrows.
